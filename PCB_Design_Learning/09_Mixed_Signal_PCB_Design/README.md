# 09 - Mixed Signal PCB Design

# Overview

Modern embedded systems rarely contain only digital or only analog circuits. Most practical electronic products combine microcontrollers, sensors, analog front-end circuits, communication interfaces, switching regulators, and power electronics on the same PCB.

A PCB containing both analog and digital circuitry is called a **Mixed-Signal PCB**.

Designing a mixed-signal PCB is significantly more challenging than designing a purely digital board because analog circuits are highly sensitive to noise generated by digital switching.

This chapter explains the principles of mixed-signal PCB design, signal isolation, grounding strategies, power supply planning, analog and digital partitioning, ADC layout considerations, and routing practices required to achieve reliable system performance.

# What is a Mixed Signal PCB?

A mixed-signal PCB contains both:

- Analog Circuits
- Digital Circuits

Examples:

Analog

- Temperature Sensor
- Pressure Sensor
- Current Sense Amplifier
- ADC Input
- Op-Amp
- DAC Output

Digital

- STM32
- ESP32
- Raspberry Pi
- Memory
- USB
- SPI
- UART
- CAN
- Ethernet

The challenge is preventing digital switching noise from degrading sensitive analog signals.

---

# Why is Mixed Signal Design Difficult?

Digital circuits continuously switch between HIGH and LOW logic states.

Example:

```
HIGH
────────────

LOW
____________
```

Each transition causes:

- Large transient current
- High di/dt
- Fast dv/dt
- Electromagnetic radiation

Analog circuits measure very small voltages.

For example:

Temperature sensor output

```
35 mV
```

Pressure sensor

```
120 mV
```

Current sense amplifier

```
25 mV
```

If digital switching noise couples into these signals,

measurement accuracy decreases.

---

# Sources of Digital Noise

Common digital noise sources include:

- MCU clock
- Crystal oscillator
- USB
- Ethernet
- SPI
- High-speed GPIO
- Switching regulators
- PWM outputs
- Motor drivers

These signals generate rapidly changing electric and magnetic fields.

---

# Analog Circuits

Analog circuits process continuously varying signals.

Examples include:

- Sensors
- Operational amplifiers
- ADC inputs
- DAC outputs
- Instrumentation amplifiers
- Reference voltage circuits

Analog circuits are sensitive to:

- EMI
- Crosstalk
- Ground noise
- Power supply ripple

---

# Digital Circuits

Digital circuits process discrete logic levels.

Examples:

- MCU
- FPGA
- Memory
- Communication ICs

Digital circuits tolerate much larger voltage margins than analog circuits but generate much more switching noise.

---

# Functional Partitioning

The first step in mixed-signal PCB design is functional partitioning.

Example:

```
+--------------------------------------------------+

 ANALOG SECTION

 Sensor
 Op-Amp
 ADC Reference

---------------------------------------------------

 DIGITAL SECTION

 STM32
 Memory
 USB
 CAN
 SPI

---------------------------------------------------

 POWER SECTION

 Buck Converter
 LDO
 Protection

+--------------------------------------------------+
```

Each functional block should be placed together before routing begins.

---

# Physical Separation

Analog and digital sections should be physically separated.

Incorrect:

```
Sensor MCU Sensor MCU
```

Correct:

```
Analog Area

Sensor
ADC
Reference

---------------------

Digital Area

STM32
USB
Memory
```

This reduces electromagnetic coupling.

---

# ADC Placement

The Analog-to-Digital Converter acts as the interface between analog and digital domains.

If the ADC is integrated inside the MCU:

- Place analog input circuitry close to the ADC pins.
- Keep analog traces short.
- Keep digital clocks away from ADC inputs.
- Route analog signals before noisy digital signals.

---

# Grounding Strategy

Ground is one of the most misunderstood concepts in mixed-signal PCB design.

Ground is not an ideal zero-volt conductor.

Every ground path has:

- Resistance
- Inductance
- Voltage drop

Improper grounding allows digital return currents to flow through analog sections, introducing measurement errors.

---

# AGND and DGND

Many mixed-signal ICs provide separate ground pins:

- AGND (Analog Ground)
- DGND (Digital Ground)

Their purpose is to isolate noisy digital return currents from sensitive analog circuitry inside the device.

**Important:** Whether AGND and DGND should be joined externally, and where, depends on the IC datasheet. Many manufacturers recommend connecting them at a single location or through a continuous ground plane according to their layout guidelines.

Always follow the device manufacturer's recommendations rather than applying a universal rule.

---

# Ground Return Current

Current always returns to its source.

Digital Return Current

```
MCU

↓

Ground Plane

↓

Power Supply
```

Analog Return Current

```
Sensor

↓

Ground Plane

↓

Reference
```

A good layout prevents these return paths from unnecessarily sharing the same high-current routes.

---

# Power Supply Isolation

Using separate filtering for analog and digital supplies helps reduce conducted noise.

Example:

```
5V

↓

Buck Converter

↓

3.3V Digital

↓

Ferrite Bead

↓

3.3V Analog

↓

Sensor
```

The ferrite bead attenuates high-frequency noise while allowing DC power to pass.

The exact filtering network should be selected based on the application and the component datasheets.

---

# Analog Routing Guidelines

Analog traces should be:

- Short
- Direct
- Away from clocks
- Away from switching regulators
- Away from USB differential pairs
- Away from high-current traces

Avoid routing analog signals parallel to noisy digital traces for long distances.

---

# Digital Routing Guidelines

Digital traces should:

- Have continuous return paths
- Maintain controlled impedance where required
- Follow differential routing rules for high-speed interfaces
- Avoid crossing sensitive analog regions

---

# Decoupling Strategy

Every mixed-signal IC requires local decoupling.

Typical placement:

```
VDD

|

0.1µF

|

IC

|

GND
```

Place the capacitor as close as possible to the power pin to minimize loop inductance.

Additional bulk capacitance may be required depending on the device.

---

# Clock Routing

Clock signals are among the strongest sources of digital noise.

Best practices:

- Keep clock traces short.
- Avoid routing clocks near analog inputs.
- Minimize loop area.
- Follow the MCU or oscillator layout recommendations.

---

# Common Mistakes

❌ Placing analog and digital circuits randomly

❌ Routing ADC inputs beside USB or clock traces

❌ Ignoring return-current paths

❌ Sharing noisy power supplies without proper filtering

❌ Placing switching regulators next to analog front ends

❌ Ignoring manufacturer layout recommendations

# Key Takeaways

Mixed-signal PCB design requires more than simply separating analog and digital components. Successful designs control current paths, manage noise sources, follow appropriate grounding strategies, isolate sensitive circuits from switching activity, and implement power filtering based on the requirements of the specific application and device datasheets.

Understanding these principles is essential for designing reliable embedded systems that combine precision analog measurements with high-speed digital processing.
